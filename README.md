# Engine-Core

## Cloning the repository

This project uses the Git submodules: ImGui.

Clone with:

```bash
git clone --recurse-submodules https://github.com/arubaii/Engine-Core.git
```
The scene adopts an ECS for entity management, as opposed to an object-oriented hierarchy. Many features, such as the UI and model loading system, are still a work in progress.
